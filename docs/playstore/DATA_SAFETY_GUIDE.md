### نظرة عامة لسياسة أمان البيانات

يهدف هذا المستند إلى توفير إجابات دقيقة ومطابقة تماماً لنموذج **أمان البيانات (Data Safety Section)** في لوحة تحكم مطوري جوجل بلاي (**Google Play Console**) لتطبيق **مصروف (Masroof)**.

يعتمد تطبيق **مصروف** فلسفة **العمل المحلي أولاً (Offline-First)**، ولا يجمع أي بيانات افتراضياً. كافة عمليات الجمع السحابية هي **اختيارية 100%** لغرض وحيد وهو **النسخ الاحتياطي السحابي واستعادة البيانات عند تغيير الهاتف**.

### 3. ممارسات الأمان والحماية (Security Practices)

1. **التشفير أثناء النقل (Encryption in Transit):**
   - كافة الاتصالات السحابية تمر حصرياً عبر قنوات اتصال مؤمنة ومشفرة بمعيار **TLS / HTTPS**.
2. **ضغط البيانات وتجزئتها محلياً:**
   - يتم ضغط كامل البيانات بخوارزمية **GZIP** لتقليل حجم النقل بنسبة تتجاوز 80%.
   - يتم احتساب بصمة رقمية مشفرة **SHA-256** والتحقق منها قبل أي عملية استعادة لضمان سلامة البيانات ومنع أي تلاعب.
3. **عزل المستخدمين الصارم (Zero-Trust User Isolation):**
   - قواعد الأمان السحابية (`firestore.rules`) تمنع منعاً باتاً أي مستخدم من قراءة أو كتابة أو حذف أي بيانات تخص مستخدماً آخر.
4. **الحذف الكامل والفوري:**
   - عند طلب المستخدم حذف حسابه السحابي، يتم حذف كافة مستندات النسخ وأجزائها المضغوطة فورياً ودون أي تأخير، مع تخيير المستخدم بشأن بقاء بياناته المحلية في هاتفه.
